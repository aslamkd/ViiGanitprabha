1) নীচের অনুপাতগুলি সমান কিনা দেখি ও চারটি সংখ্যা সমানুপাতী কিনা লিখি:

নিয়ম (Rule): দুটি অনুপাত লঘিষ্ঠ আকারে প্রকাশ করার পর যদি তাদের মান একই হয়, তবে তারা সমান। আর দুটি অনুপাত সমান হলে সেই অনুপাত দুটির পদ চারটি সমানুপাতে থাকে।

(a) $7 : 2 \text{ এবং } 28 : 8$

প্রথম অনুপাত = $7 : 2$
দ্বিতীয় অনুপাত = $28 : 8 = \frac{28}{4} : \frac{8}{4} = 7 : 2$

যেহেতু $7 : 2 = 28 : 8$, তাই অনুপাত দুটি সমান।

উত্তর: 7, 2, 28, 8 সংখ্যা চারটি সমানুপাতী।
(b) $9 : 7 \text{ এবং } 18 : 14$

প্রথম অনুপাত = $9 : 7$
দ্বিতীয় অনুপাত = $18 : 14 = \frac{18}{2} : \frac{14}{2} = 9 : 7$

যেহেতু $9 : 7 = 18 : 14$, তাই অনুপাত দুটি সমান।

উত্তর: 9, 7, 18, 14 সংখ্যা চারটি সমানুপাতী।
(c) $1.5 : 3 \text{ এবং } 4.5 : 9$

প্রথম অনুপাত = $1.5 : 3 = \frac{15}{10} : 3 = 15 : 30 = 1 : 2$
দ্বিতীয় অনুপাত = $4.5 : 9 = \frac{45}{10} : 9 = 45 : 90 = 1 : 2$

যেহেতু দুটি অনুপাতের লঘিষ্ঠ মানই $1 : 2$, তাই অনুপাত দুটি সমান।

উত্তর: 1.5, 3, 4.5, 9 সংখ্যা চারটি সমানুপাতী।
(d) $7 : 3 \text{ এবং } 5 : 2$

প্রথম অনুপাত = $7 : 3$
দ্বিতীয় অনুপাত = $5 : 2$

এই অনুপাত দুটিকে আর লঘিষ্ঠ করা যায় না এবং এদের মান আলাদা।
যেহেতু $7 : 3 \neq 5 : 2$, তাই অনুপাত দুটি সমান নয়।

উত্তর: 7, 3, 5, 2 সংখ্যা চারটি সমানুপাতী নয়।
(e) $3ab : 4aq \text{ এবং } 6b : 8q$

প্রথম অনুপাত = $3ab : 4aq = 3b : 4q$   (উভয় পদকে a দিয়ে ভাগ করে)
দ্বিতীয় অনুপাত = $6b : 8q = 3b : 4q$   (উভয় পদকে 2 দিয়ে ভাগ করে)

যেহেতু $3b : 4q = 3b : 4q$, তাই অনুপাত দুটি সমান।

উত্তর: 3ab, 4aq, 6b, 8q সমানুপাতী।
(f) $5.2 : 6.5 \text{ এবং } 4 : 5$

প্রথম অনুপাত = $5.2 : 6.5 = \frac{52}{10} : \frac{65}{10} = 52 : 65 = 4 : 5$   (13 দিয়ে ভাগ করে)
দ্বিতীয় অনুপাত = $4 : 5$

যেহেতু $4 : 5 = 4 : 5$, তাই অনুপাত দুটি সমান।

উত্তর: 5.2, 6.5, 4, 5 সমানুপাতী।
(g) $3y : 7y \text{ এবং } 12p : 28p$

প্রথম অনুপাত = $3y : 7y = 3 : 7$   (y দিয়ে ভাগ করে)
দ্বিতীয় অনুপাত = $12p : 28p = 12 : 28 = 3 : 7$   (4p দিয়ে ভাগ করে)

যেহেতু $3 : 7 = 3 : 7$, তাই অনুপাত দুটি সমান।

উত্তর: 3y, 7y, 12p, 28p সমানুপাতী।
(h) $5pq : 7pr \text{ এবং } 15s : 21q$

প্রথম অনুপাত = $5pq : 7pr = 5q : 7r$
দ্বিতীয় অনুপাত = $15s : 21q = 5s : 7q$   (3 দিয়ে ভাগ করে)

যেহেতু $5q : 7r \neq 5s : 7q$, তাই অনুপাত দুটি সমান নয়।

উত্তর: 5pq, 7pr, 15s, 21q সমানুপাতী নয়।
2) একটি আয়তাকার চিত্রের দৈর্ঘ্য 10 সেমি. এবং প্রস্থ 6 সেমি.। চিত্রটির দৈর্ঘ্য ও প্রস্থ 2 সেমি. বাড়ানো হলো। আয়তাকার চিত্রটির দৈর্ঘ্য ও প্রস্থ একই অনুপাত থাকবে কিনা দেখি।

প্রথমে, আয়তাকার চিত্রের দৈর্ঘ্য = $10$ সেমি. এবং প্রস্থ = $6$ সেমি.

$\therefore$ প্রাথমিক অবস্থায় দৈর্ঘ্য ও প্রস্থের অনুপাত
$= 10 : 6$
$= 5 : 3$   (উভয় পদকে 2 দিয়ে ভাগ করে)

এখন দৈর্ঘ্য 2 সেমি. বাড়ানো হলে নতুন দৈর্ঘ্য = $10 + 2 = 12$ সেমি.
এবং প্রস্থ 2 সেমি. বাড়ানো হলে নতুন প্রস্থ = $6 + 2 = 8$ সেমি.

$\therefore$ নতুন অবস্থায় দৈর্ঘ্য ও প্রস্থের অনুপাত
$= 12 : 8$
$= 3 : 2$   (উভয় পদকে 4 দিয়ে ভাগ করে)

দেখা যাচ্ছে, $5 : 3 \neq 3 : 2$

উত্তর: না, আয়তাকার চিত্রটির দৈর্ঘ্য ও প্রস্থ একই অনুপাতে থাকবে না।
3) পরাণবাবু 500 গ্রাম চিনি 17.50 টাকায় কিনলেন এবং দীপেনবাবু 2 কিগ্রা. চিনি 70 টাকায় কিনলেন। চিনির পরিমাণ ও দাম সমানুপাতে আছে কিনা দেখি।

প্রথমে চিনির পরিমাণের অনুপাত নির্ণয় করি:

পরাণবাবুর চিনির পরিমাণ = $500$ গ্রাম।
দীপেনবাবুর চিনির পরিমাণ = $2$ কিগ্রা. = $2 \times 1000$ গ্রাম = $2000$ গ্রাম।

$\therefore$ চিনির পরিমাণের অনুপাত = $500 : 2000 = 5 : 20 = 1 : 4$

এবার চিনির দামের অনুপাত নির্ণয় করি:

পরাণবাবুর চিনির দাম = $17.50$ টাকা।
দীপেনবাবুর চিনির দাম = $70$ টাকা।

$\therefore$ চিনির দামের অনুপাত = $17.50 : 70$

উভয় পদকে 100 দিয়ে গুণ করে দশমিক তুললে পাই,
$= 1750 : 7000$
$= 175 : 700$
$= 25 : 100$   (7 দিয়ে ভাগ করে)
$= 1 : 4$   (25 দিয়ে ভাগ করে)

যেহেতু, চিনির পরিমাণের অনুপাত ($1 : 4$) এবং চিনির দামের অনুপাত ($1 : 4$) সমান।

উত্তর: হ্যাঁ, চিনির পরিমাণ ও দাম সমানুপাতে আছে।
4) ফাঁকা ঘর পূরণ করি: (i) $5 : 7 :: 25 : \square$ (ii) $6 : 7 :: \square : 35$ (iii) $21 : 28 :: 3 : \square$ (iv) $9 : 24 :: \square : 8$

নিয়ম: চারটি সংখ্যা $a, b, c, d$ সমানুপাতে থাকলে $a : b :: c : d$ হয়। অর্থাৎ, $\frac{a}{b} = \frac{c}{d}$ বা $a \times d = b \times c$ (প্রথম পদ $\times$ চতুর্থ পদ = দ্বিতীয় পদ $\times$ তৃতীয় পদ)।

(i) $5 : 7 :: 25 : \square$

ধরি, ফাঁকা ঘরটির মান $x$।
$\therefore 5 : 7 = 25 : x$
$\Rightarrow \frac{5}{7} = \frac{25}{x}$
$\Rightarrow 5 \times x = 25 \times 7$
$\Rightarrow x = \frac{25 \times 7}{5}$
$\Rightarrow x = 5 \times 7 = 35$

উত্তর: ফাঁকা ঘরে 35 বসবে।
(ii) $6 : 7 :: \square : 35$

ধরি, ফাঁকা ঘরটির মান $x$।
$\therefore 6 : 7 = x : 35$
$\Rightarrow \frac{6}{7} = \frac{x}{35}$
$\Rightarrow 7 \times x = 6 \times 35$
$\Rightarrow x = \frac{6 \times 35}{7}$
$\Rightarrow x = 6 \times 5 = 30$

উত্তর: ফাঁকা ঘরে 30 বসবে।
(iii) $21 : 28 :: 3 : \square$

ধরি, ফাঁকা ঘরটির মান $x$।
$\therefore 21 : 28 = 3 : x$
$\Rightarrow \frac{21}{28} = \frac{3}{x}$

$\frac{21}{28}$ কে লঘিষ্ঠ করলে হয় $\frac{3}{4}$ (৭ দিয়ে ভাগ করে)।
$\Rightarrow \frac{3}{4} = \frac{3}{x}$
উপরের লব দুটি সমান (3=3), তাই হর দুটিও সমান হবে।
$\Rightarrow x = 4$

উত্তর: ফাঁকা ঘরে 4 বসবে।
(iv) $9 : 24 :: \square : 8$

ধরি, ফাঁকা ঘরটির মান $x$।
$\therefore 9 : 24 = x : 8$
$\Rightarrow \frac{9}{24} = \frac{x}{8}$

$\frac{9}{24}$ কে লঘিষ্ঠ করলে হয় $\frac{3}{8}$ (৩ দিয়ে ভাগ করে)।
$\Rightarrow \frac{3}{8} = \frac{x}{8}$
নীচের হর দুটি সমান (8=8), তাই লব দুটিও সমান হবে।
$\Rightarrow x = 3$

উত্তর: ফাঁকা ঘরে 3 বসবে।
