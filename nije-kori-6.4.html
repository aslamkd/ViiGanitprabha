1) যোগ করি :
(i) $(-5x + 3y)$ ও $(18x - 15y)$
(ii) $(7a - 8b + 2c)$ ও $(2a + 3b - d)$

(i) $(-5x + 3y)$ ও $(18x - 15y)$

$= (-5x + 3y) + (18x - 15y)$

$= -5x + 3y + 18x - 15y$

[সদৃশ পদগুলিকে একসাথে সাজিয়ে পাই]

$= (-5x + 18x) + (3y - 15y)$

$= 13x - 12y$

উত্তর: নির্ণেয় যোগফল $\color{#059669}{\mathbf{\boxed{13x - 12y}}}$

(ii) $(7a - 8b + 2c)$ ও $(2a + 3b - d)$

$= (7a - 8b + 2c) + (2a + 3b - d)$

$= 7a - 8b + 2c + 2a + 3b - d$

[সদৃশ পদগুলিকে একসাথে সাজিয়ে পাই]

$= (7a + 2a) + (-8b + 3b) + 2c - d$

$= 9a - 5b + 2c - d$

উত্তর: নির্ণেয় যোগফল $\color{#059669}{\mathbf{\boxed{9a - 5b + 2c - d}}}$
2) বিয়োগ করি :
(i) $(4mn + m + n)$ থেকে $(-mn - m + n)$
(ii) $(p^2 + q^2 - pq + p^2q)$ থেকে $(2q^2 + 3p^2 - qp + pq^2)$

(i) $(4mn + m + n)$ থেকে $(-mn - m + n)$

$= (4mn + m + n) - (-mn - m + n)$

[বিয়োগের জন্য দ্বিতীয় সংখ্যামালার ভেতরের চিহ্ন পরিবর্তন হবে]

$= 4mn + m + n + mn + m - n$

[সদৃশ পদগুলিকে একসাথে সাজিয়ে পাই]

$= (4mn + mn) + (m + m) + (n - n)$

$= 5mn + 2m + 0$

$= 5mn + 2m$

$= m(5n + 2)$

উত্তর: নির্ণেয় বিয়োগফল $\color{#059669}{\mathbf{\boxed{5mn + 2m}}}$ বা $\color{#059669}{\mathbf{\boxed{m(5n + 2)}}}$

(ii) $(p^2 + q^2 - pq + p^2q)$ থেকে $(2q^2 + 3p^2 - qp + pq^2)$

$= (p^2 + q^2 - pq + p^2q) - (2q^2 + 3p^2 - qp + pq^2)$

[বিয়োগের জন্য দ্বিতীয় সংখ্যামালার ভেতরের চিহ্ন পরিবর্তন হবে। মনে রাখতে হবে $qp = pq$]

$= p^2 + q^2 - pq + p^2q - 2q^2 - 3p^2 + pq - pq^2$

[সদৃশ পদগুলিকে একসাথে সাজিয়ে পাই]

$= (p^2 - 3p^2) + (q^2 - 2q^2) + (-pq + pq) + p^2q - pq^2$

$= -2p^2 - q^2 + 0 + p^2q - pq^2$

$= -2p^2 - q^2 + p^2q - pq^2$

উত্তর: নির্ণেয় বিয়োগফল $\color{#059669}{\mathbf{\boxed{-2p^2 - q^2 + p^2q - pq^2}}}$
