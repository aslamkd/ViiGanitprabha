1. $(x+a)(x+b) = x^2 + (a+b)x + ab$ —এই অভেদের সাহায্যে নীচের বীজগাণিতিক সংখ্যামালাগুলি গুণ করি।

(i) $(x+7)(x+1)$    (ii) $(x-8)(x-2)$    (iii) $(x+9)(x-6)$
(iv) $(2x+1)(2x-1)$    (v) $(xy-4)(xy+2)$    (vi) $(a^2+5)(a^2-4)$

(i) $(x+7)(x+1)$

এখানে $a = 7$ এবং $b = 1$। সূত্র প্রয়োগ করে পাই,

$(x+7)(x+1) = x^2 + (7+1)x + (7 \times 1)$

$= x^2 + 8x + 7$

উত্তর: $\color{#059669}{\mathbf{\boxed{x^2 + 8x + 7}}}$

(ii) $(x-8)(x-2)$

এখানে $a = -8$ এবং $b = -2$। সূত্র প্রয়োগ করে পাই,

$(x-8)(x-2) = x^2 + (-8 - 2)x + (-8)(-2)$

$= x^2 - 10x + 16$

উত্তর: $\color{#059669}{\mathbf{\boxed{x^2 - 10x + 16}}}$

(iii) $(x+9)(x-6)$

এখানে $a = 9$ এবং $b = -6$। সূত্র প্রয়োগ করে পাই,

$(x+9)(x-6) = x^2 + (9 - 6)x + (9)(-6)$

$= x^2 + 3x - 54$

উত্তর: $\color{#059669}{\mathbf{\boxed{x^2 + 3x - 54}}}$

(iv) $(2x+1)(2x-1)$

এখানে $x$ এর জায়গায় $2x$, $a = 1$ এবং $b = -1$। সূত্র প্রয়োগ করে পাই,

$(2x+1)(2x-1) = (2x)^2 + (1 - 1)(2x) + (1)(-1)$

$= 4x^2 + (0)(2x) - 1$

$= 4x^2 - 1$

উত্তর: $\color{#059669}{\mathbf{\boxed{4x^2 - 1}}}$

(v) $(xy-4)(xy+2)$

এখানে $x$ এর জায়গায় $xy$, $a = -4$ এবং $b = 2$। সূত্র প্রয়োগ করে পাই,

$(xy-4)(xy+2) = (xy)^2 + (-4 + 2)(xy) + (-4)(2)$

$= x^2y^2 + (-2)(xy) - 8$

$= x^2y^2 - 2xy - 8$

উত্তর: $\color{#059669}{\mathbf{\boxed{x^2y^2 - 2xy - 8}}}$

(vi) $(a^2+5)(a^2-4)$

এখানে $x$ এর জায়গায় $a^2$, $a = 5$ এবং $b = -4$। সূত্র প্রয়োগ করে পাই,

$(a^2+5)(a^2-4) = (a^2)^2 + (5 - 4)(a^2) + (5)(-4)$

$= a^4 + (1)(a^2) - 20$

$= a^4 + a^2 - 20$

উত্তর: $\color{#059669}{\mathbf{\boxed{a^4 + a^2 - 20}}}$
2. সূত্রের সাহায্যে দেখাই যে—
(i) $(2x+3y)^2 - (2x-3y)^2 = 24xy$
(ii) $(a+2b)^2 + (a-2b)^2 = 2(a^2+4b^2)$
(iii) $(l+m)^2 = (l-m)^2 + 4lm$
(iv) $(2p-q)^2 = (2p+q)^2 - 8pq$
(v) $(3m+4n)^2 = (3m-4n)^2 + 48mn$
(vi) $(6x+7y)^2 - 84xy = 36x^2+49y^2$
(vii) $(3a-4b)^2 + 24ab = 9a^2+16b^2$
(viii) $\left(2a+\frac{1}{a}\right)^2 = \left(2a-\frac{1}{a}\right)^2 + 8$

(i) $(2x+3y)^2 - (2x-3y)^2 = 24xy$

বামপক্ষ (LHS):

$= (2x+3y)^2 - (2x-3y)^2$

[আমরা জানি, $(a+b)^2 - (a-b)^2 = 4ab$]

$= 4(2x)(3y)$

$= 24xy$

$=$ ডানপক্ষ (RHS)

(প্রমাণিত)

(ii) $(a+2b)^2 + (a-2b)^2 = 2(a^2+4b^2)$

বামপক্ষ (LHS):

$= (a+2b)^2 + (a-2b)^2$

[আমরা জানি, $(x+y)^2 + (x-y)^2 = 2(x^2+y^2)$]

$= 2\{a^2 + (2b)^2\}$

$= 2(a^2 + 4b^2)$

$=$ ডানপক্ষ (RHS)

(প্রমাণিত)

(iii) $(l+m)^2 = (l-m)^2 + 4lm$

ডানপক্ষ (RHS):

$= (l-m)^2 + 4lm$

$= (l^2 - 2lm + m^2) + 4lm$

$= l^2 + 2lm + m^2$

$= (l+m)^2$

$=$ বামপক্ষ (LHS)

(প্রমাণিত)

(iv) $(2p-q)^2 = (2p+q)^2 - 8pq$

ডানপক্ষ (RHS):

$= (2p+q)^2 - 8pq$

$= \{(2p)^2 + 2(2p)(q) + q^2\} - 8pq$

$= 4p^2 + 4pq + q^2 - 8pq$

$= 4p^2 - 4pq + q^2$

$= (2p)^2 - 2(2p)(q) + q^2$

$= (2p-q)^2$

$=$ বামপক্ষ (LHS)

(প্রমাণিত)

(v) $(3m+4n)^2 = (3m-4n)^2 + 48mn$

ডানপক্ষ (RHS):

$= (3m-4n)^2 + 48mn$

$= \{(3m)^2 - 2(3m)(4n) + (4n)^2\} + 48mn$

$= 9m^2 - 24mn + 16n^2 + 48mn$

$= 9m^2 + 24mn + 16n^2$

$= (3m)^2 + 2(3m)(4n) + (4n)^2$

$= (3m+4n)^2$

$=$ বামপক্ষ (LHS)

(প্রমাণিত)

(vi) $(6x+7y)^2 - 84xy = 36x^2+49y^2$

বামপক্ষ (LHS):

$= (6x+7y)^2 - 84xy$

$= \{(6x)^2 + 2(6x)(7y) + (7y)^2\} - 84xy$

$= 36x^2 + 84xy + 49y^2 - 84xy$

$= 36x^2 + 49y^2$

$=$ ডানপক্ষ (RHS)

(প্রমাণিত)

(vii) $(3a-4b)^2 + 24ab = 9a^2+16b^2$

বামপক্ষ (LHS):

$= (3a-4b)^2 + 24ab$

$= \{(3a)^2 - 2(3a)(4b) + (4b)^2\} + 24ab$

$= 9a^2 - 24ab + 16b^2 + 24ab$

$= 9a^2 + 16b^2$

$=$ ডানপক্ষ (RHS)

(প্রমাণিত)

(viii) $\left(2a+\frac{1}{a}\right)^2 = \left(2a-\frac{1}{a}\right)^2 + 8$

ডানপক্ষ (RHS):

$= \left(2a-\frac{1}{a}\right)^2 + 8$

$= \left( (2a)^2 - 2(2a)\left(\frac{1}{a}\right) + \left(\frac{1}{a}\right)^2 \right) + 8$

$= 4a^2 - 4 + \frac{1}{a^2} + 8$

$= 4a^2 + 4 + \frac{1}{a^2}$

$= (2a)^2 + 2(2a)\left(\frac{1}{a}\right) + \left(\frac{1}{a}\right)^2$

$= \left(2a+\frac{1}{a}\right)^2$

$=$ বামপক্ষ (LHS)

(প্রমাণিত)
3. প্রতিক্ষেত্রে সূত্রের সাহায্যে সমস্যাগুলির সমাধান করি।

(i) $x-y=3, xy=28$ হলে $x^2+y^2$ -এর মান কত লিখি।

আমরা জানি, $x^2+y^2 = (x-y)^2 + 2xy$

দেওয়া আছে, $x-y = 3$ এবং $xy = 28$

মান বসিয়ে পাই,

$x^2+y^2 = (3)^2 + 2(28)$

$= 9 + 56$

$= 65$

উত্তর: নির্ণেয় মান $\color{#059669}{\mathbf{\boxed{65}}}$
3. (ii) $a^2+b^2=52, a-b=2$ হলে, $ab$ - এর মান কত লিখি।

আমরা জানি, $a^2+b^2 = (a-b)^2 + 2ab$

দেওয়া আছে, $a^2+b^2 = 52$ এবং $a-b = 2$

মান বসিয়ে পাই,

$52 = (2)^2 + 2ab$

বা, $52 = 4 + 2ab$

বা, $2ab = 52 - 4$

বা, $2ab = 48$

বা, $ab = \frac{48}{2} = 24$

উত্তর: $ab$ এর মান $\color{#059669}{\mathbf{\boxed{24}}}$
3. (iii) $l^2+m^2=13$ এবং $l+m=5$ হলে $lm$ - এর মান কত লিখি।

আমরা জানি, $l^2+m^2 = (l+m)^2 - 2lm$

দেওয়া আছে, $l^2+m^2 = 13$ এবং $l+m = 5$

মান বসিয়ে পাই,

$13 = (5)^2 - 2lm$

বা, $13 = 25 - 2lm$

বা, $2lm = 25 - 13$

বা, $2lm = 12$

বা, $lm = \frac{12}{2} = 6$

উত্তর: $lm$ এর মান $\color{#059669}{\mathbf{\boxed{6}}}$
3. (iv) $a+\frac{1}{a}=4$ হলে $a^2+\frac{1}{a^2}$ -এর মান কত লিখি।

দেওয়া আছে, $a+\frac{1}{a}=4$

উভয়পক্ষকে বর্গ করে পাই,

$\left(a+\frac{1}{a}\right)^2 = (4)^2$

বা, $a^2 + 2(a)\left(\frac{1}{a}\right) + \frac{1}{a^2} = 16$

বা, $a^2 + 2 + \frac{1}{a^2} = 16$

বা, $a^2 + \frac{1}{a^2} = 16 - 2$

বা, $a^2 + \frac{1}{a^2} = 14$

উত্তর: নির্ণেয় মান $\color{#059669}{\mathbf{\boxed{14}}}$
3. (v) $a-\frac{1}{a}=4$ হলে $a^2+\frac{1}{a^2}$ -এর মান কত লিখি।

আমরা জানি, $x^2+y^2 = (x-y)^2 + 2xy$

তাহলে, $a^2+\frac{1}{a^2} = \left(a-\frac{1}{a}\right)^2 + 2(a)\left(\frac{1}{a}\right)$

$= (4)^2 + 2$

$= 16 + 2 = 18$

উত্তর: নির্ণেয় মান $\color{#059669}{\mathbf{\boxed{18}}}$
3. (vi) $5x+\frac{1}{x}=6$ হলে দেখাই যে $25x^2+\frac{1}{x^2}=26$

বামপক্ষ (LHS): $25x^2+\frac{1}{x^2}$

$= (5x)^2 + \left(\frac{1}{x}\right)^2$

$= \left(5x+\frac{1}{x}\right)^2 - 2(5x)\left(\frac{1}{x}\right)$

এখানে $5x+\frac{1}{x} = 6$ বসিয়ে পাই,

$= (6)^2 - 10$

$= 36 - 10$

$= 26$

$=$ ডানপক্ষ (RHS)

(প্রমাণিত)
3. (vii) $2x+\frac{1}{x}=5$ হলে $4x^2+\frac{1}{x^2}$ -এর মান লিখি।

প্রদত্ত রাশি: $4x^2+\frac{1}{x^2}$

$= (2x)^2 + \left(\frac{1}{x}\right)^2$

$= \left(2x+\frac{1}{x}\right)^2 - 2(2x)\left(\frac{1}{x}\right)$

এখানে $2x+\frac{1}{x} = 5$ বসিয়ে পাই,

$= (5)^2 - 4$

$= 25 - 4$

$= 21$

উত্তর: নির্ণেয় মান $\color{#059669}{\mathbf{\boxed{21}}}$
3. (viii) $\frac{x}{y}+\frac{y}{x}=3$ হলে $\frac{x^2}{y^2}+\frac{y^2}{x^2}$ -এর মান লিখি।

প্রদত্ত রাশি: $\frac{x^2}{y^2}+\frac{y^2}{x^2}$

$= \left(\frac{x}{y}\right)^2 + \left(\frac{y}{x}\right)^2$

$= \left(\frac{x}{y}+\frac{y}{x}\right)^2 - 2\left(\frac{x}{y}\right)\left(\frac{y}{x}\right)$

এখানে $\frac{x}{y}+\frac{y}{x} = 3$ বসিয়ে পাই,

$= (3)^2 - 2(1)$

$= 9 - 2$

$= 7$

উত্তর: নির্ণেয় মান $\color{#059669}{\mathbf{\boxed{7}}}$
3. (ix) $x^2+y^2=4xy$ হলে প্রমাণ করি যে $x^4+y^4=14x^2y^2$

দেওয়া আছে, $x^2+y^2=4xy$

উভয়পক্ষকে বর্গ করে পাই,

$(x^2+y^2)^2 = (4xy)^2$

বা, $(x^2)^2 + 2(x^2)(y^2) + (y^2)^2 = 16x^2y^2$

বা, $x^4 + 2x^2y^2 + y^4 = 16x^2y^2$

বা, $x^4 + y^4 = 16x^2y^2 - 2x^2y^2$

বা, $x^4 + y^4 = 14x^2y^2$

(প্রমাণিত)
3. (x) $2a+\frac{1}{3a}=6$ হলে $4a^2+\frac{1}{9a^2}$ -এর মান কত লিখি।

প্রদত্ত রাশি: $4a^2+\frac{1}{9a^2}$

$= (2a)^2 + \left(\frac{1}{3a}\right)^2$

$= \left(2a+\frac{1}{3a}\right)^2 - 2(2a)\left(\frac{1}{3a}\right)$

এখানে $2a+\frac{1}{3a} = 6$ বসিয়ে পাই,

$= (6)^2 - \frac{4}{3}$

$= 36 - \frac{4}{3}$

$= \frac{108 - 4}{3}$

$= \frac{104}{3} = 34\frac{2}{3}$

উত্তর: নির্ণেয় মান $\color{#059669}{\mathbf{\boxed{34\frac{2}{3}}}}$ বা $\color{#059669}{\mathbf{\boxed{\frac{104}{3}}}}$
3. (xi) $5a+\frac{1}{7a}=5$ হলে $25a^2+\frac{1}{49a^2}$ -এর মান কত লিখি।

প্রদত্ত রাশি: $25a^2+\frac{1}{49a^2}$

$= (5a)^2 + \left(\frac{1}{7a}\right)^2$

$= \left(5a+\frac{1}{7a}\right)^2 - 2(5a)\left(\frac{1}{7a}\right)$

এখানে $5a+\frac{1}{7a} = 5$ বসিয়ে পাই,

$= (5)^2 - \frac{10}{7}$

$= 25 - \frac{10}{7}$

$= \frac{175 - 10}{7}$

$= \frac{165}{7} = 23\frac{4}{7}$

উত্তর: নির্ণেয় মান $\color{#059669}{\mathbf{\boxed{23\frac{4}{7}}}}$ বা $\color{#059669}{\mathbf{\boxed{\frac{165}{7}}}}$
3. (xii) $2x-\frac{1}{x}=4$ হলে $x^2+\frac{1}{4x^2}$ -এর মান লিখি।

দেওয়া আছে, $2x-\frac{1}{x}=4$

উভয়পক্ষকে 2 দিয়ে ভাগ করে পাই,

$x - \frac{1}{2x} = 2$

এবার প্রদত্ত রাশিটি হলো: $x^2+\frac{1}{4x^2}$

$= (x)^2 + \left(\frac{1}{2x}\right)^2$

$= \left(x-\frac{1}{2x}\right)^2 + 2(x)\left(\frac{1}{2x}\right)$

মান বসিয়ে পাই,

$= (2)^2 + 1$

$= 4 + 1 = 5$

উত্তর: নির্ণেয় মান $\color{#059669}{\mathbf{\boxed{5}}}$
3. (xiii) $m+\frac{1}{m}=-p$ হলে দেখাই যে $m^2+\frac{1}{m^2}=p^2-2$

বামপক্ষ (LHS): $m^2+\frac{1}{m^2}$

$= \left(m+\frac{1}{m}\right)^2 - 2(m)\left(\frac{1}{m}\right)$

এখানে $m+\frac{1}{m} = -p$ বসিয়ে পাই,

$= (-p)^2 - 2$

$= p^2 - 2$

$=$ ডানপক্ষ (RHS)

(প্রমাণিত)
3. (xiv) $a^2+b^2=5ab$ হলে দেখাই যে $\frac{a^2}{b^2}+\frac{b^2}{a^2}=23$

দেওয়া আছে, $a^2+b^2=5ab$

উভয়পক্ষকে বর্গ করে পাই,

$(a^2+b^2)^2 = (5ab)^2$

বা, $(a^2)^2 + 2(a^2)(b^2) + (b^2)^2 = 25a^2b^2$

বা, $a^4 + b^4 = 25a^2b^2 - 2a^2b^2$

বা, $a^4 + b^4 = 23a^2b^2$

উভয়পক্ষকে $a^2b^2$ দিয়ে ভাগ করে পাই,

$\frac{a^4}{a^2b^2} + \frac{b^4}{a^2b^2} = \frac{23a^2b^2}{a^2b^2}$

বা, $\frac{a^2}{b^2} + \frac{b^2}{a^2} = 23$

(প্রমাণিত)
3. (xv) $6x^2-1=4x$ হলে দেখাই যে $36x^2+\frac{1}{x^2}=28$

দেওয়া আছে, $6x^2-1=4x$

উভয়পক্ষকে $x$ দিয়ে ভাগ করে পাই,

$\frac{6x^2}{x} - \frac{1}{x} = \frac{4x}{x}$

বা, $6x - \frac{1}{x} = 4$

এবার বামপক্ষ (LHS): $36x^2+\frac{1}{x^2}$

$= (6x)^2 + \left(\frac{1}{x}\right)^2$

$= \left(6x-\frac{1}{x}\right)^2 + 2(6x)\left(\frac{1}{x}\right)$

মান বসিয়ে পাই,

$= (4)^2 + 12$

$= 16 + 12 = 28$

$=$ ডানপক্ষ (RHS)

(প্রমাণিত)
3. (xvi) $m-\frac{1}{m}=p-2$ হলে দেখাই যে $m^2+\frac{1}{m^2}=p^2-4p+6$

বামপক্ষ (LHS): $m^2+\frac{1}{m^2}$

$= \left(m-\frac{1}{m}\right)^2 + 2(m)\left(\frac{1}{m}\right)$

এখানে $m-\frac{1}{m} = p-2$ বসিয়ে পাই,

$= (p-2)^2 + 2$

$= p^2 - 2(p)(2) + 2^2 + 2$

$= p^2 - 4p + 4 + 2$

$= p^2 - 4p + 6$

$=$ ডানপক্ষ (RHS)

(প্রমাণিত)
3. (xvii) $m-\frac{1}{m-2}=6$ হলে $(m-2)^2+\frac{1}{(m-2)^2}$ -এর মান কত লিখি।

দেওয়া আছে, $m-\frac{1}{m-2}=6$

উভয়পক্ষ থেকে 2 বিয়োগ করে পাই,

$m - 2 - \frac{1}{m-2} = 6 - 2$

বা, $(m-2) - \frac{1}{(m-2)} = 4$

এবার প্রদত্ত রাশিটি হলো: $(m-2)^2+\frac{1}{(m-2)^2}$

$= \left((m-2) - \frac{1}{(m-2)}\right)^2 + 2(m-2)\left(\frac{1}{m-2}\right)$

মান বসিয়ে পাই,

$= (4)^2 + 2$

$= 16 + 2 = 18$

উত্তর: নির্ণেয় মান $\color{#059669}{\mathbf{\boxed{18}}}$
