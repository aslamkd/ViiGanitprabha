নীচের ছকটি পূরণ করি (ক্রমিক সমানুপাত):

নিয়ম (Rule): তিনটি সংখ্যা ক্রমিক সমানুপাতে থাকলে তাদের প্রথম পদ : দ্বিতীয় পদ :: দ্বিতীয় পদ : তৃতীয় পদ হয়। অজানা প্রান্তীয় পদ (প্রথম বা তৃতীয়) বের করতে হলে অন্য দুটির গুণফলকে প্রদত্ত পদ দিয়ে ভাগ করতে হয়। আর অজানা মধ্যপদ বের করতে হলে প্রান্তীয় পদ দুটির গুণফলের বর্গমূল (Square Root) করতে হয়।

ক্রমিকসমানুপাতী
সংখ্যা তিনটি		 সমানুপাতে প্রকাশ ভগ্নাংশ আকারে প্রকাশ $\star$ (সংখ্যা না থাকা)
ধনাত্মক পদ
$5, 10, \star$ $5 : 10 :: 10 : \star$ $\frac{5}{10} = \frac{10}{\star}$ $\frac{10 \times 10}{5} = \mathbf{20}$
$8, \star, 4.5$ $8 : \star :: \star : 4.5$ $\frac{8}{\star} = \frac{\star}{4.5}$ $\sqrt{8 \times 4.5} = \sqrt{36} = \mathbf{6}$
$\star, 8, 16$ $\star : 8 :: 8 : 16$ $\frac{\star}{8} = \frac{8}{16}$ $\frac{8 \times 8}{16} = \mathbf{4}$
$25, \star, 81$ $25 : \star :: \star : 81$ $\frac{25}{\star} = \frac{\star}{81}$ $\sqrt{25 \times 81} = \sqrt{2025} = \mathbf{45}$
$\frac{2}{3}, \frac{4}{9}, \star$ $\frac{2}{3} : \frac{4}{9} :: \frac{4}{9} : \star$ $\frac{\frac{2}{3}}{\frac{4}{9}} = \frac{\frac{4}{9}}{\star}$ $\frac{\frac{4}{9} \times \frac{4}{9}}{\frac{2}{3}} = \frac{16}{81} \times \frac{3}{2} = \mathbf{\frac{8}{27}}$
$\frac{2}{7}, \star, \frac{16}{21}$ $\frac{2}{7} : \star :: \star : \frac{16}{21}$ $\frac{\frac{2}{7}}{\star} = \frac{\star}{\frac{16}{21}}$ $\sqrt{\frac{2}{7} \times \frac{16}{21}} = \mathbf{\sqrt{\frac{32}{147}}}$
$9, 12, \star$ $9 : 12 :: 12 : \star$ $\frac{9}{12} = \frac{12}{\star}$ $\frac{12 \times 12}{9} = \frac{144}{9} = \mathbf{16}$
$1.5, \star, 13.5$ $1.5 : \star :: \star : 13.5$ $\frac{1.5}{\star} = \frac{\star}{13.5}$ $\sqrt{1.5 \times 13.5} = \sqrt{20.25} = \mathbf{4.5}$
শিক্ষকের নোট (৬ নং সারির জন্য):

বইয়ের ৬ নং সারিতে প্রথম সংখ্যাটি ২/৭ দেওয়া থাকায় উত্তরটি একটি অমূলদ সংখ্যা ($\sqrt{32/147}$) এসেছে। যদি সংখ্যাটি ছাপার ভুলে ২/৭ এর বদলে ৩/৭ হতো, তবে উত্তরটি নিখুঁত পূর্ণবর্গ আসত: $\sqrt{\frac{3}{7} \times \frac{16}{21}} = \sqrt{\frac{16}{49}} = \mathbf{\frac{4}{7}}$। অনেক স্কুলেই অংকটি করানোর সময় ৩/৭ ধরে সংশোধন করে দেওয়া হয়।
