(i) $x^2 + 14x + 49$

$= (x)^2 + 2 \cdot x \cdot 7 + (7)^2$

[ $a^2 + 2ab + b^2 = (a+b)^2$ সূত্র প্রয়োগ করে ]

$= (x + 7)^2$

$= (x + 7)(x + 7)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(x + 7)(x + 7)}}}$

(ii) $4m^2 - 36m + 81$

$= (2m)^2 - 2 \cdot 2m \cdot 9 + (9)^2$

[ $a^2 - 2ab + b^2 = (a-b)^2$ সূত্র প্রয়োগ করে ]

$= (2m - 9)^2$

$= (2m - 9)(2m - 9)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(2m - 9)(2m - 9)}}}$

(iii) $25x^2 + 30x + 9$

$= (5x)^2 + 2 \cdot 5x \cdot 3 + (3)^2$

$= (5x + 3)^2$

$= (5x + 3)(5x + 3)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(5x + 3)(5x + 3)}}}$

(iv) $121b^2 - 88bc + 16c^2$

[ প্রশ্নে 16 এর পর $c^2$ হবে, তা ধরে নেওয়া হলো ]

$= (11b)^2 - 2 \cdot 11b \cdot 4c + (4c)^2$

$= (11b - 4c)^2$

$= (11b - 4c)(11b - 4c)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(11b - 4c)(11b - 4c)}}}$

(v) $(x^2y)^2 - 4x^2y^2$

$= (x^2y)^2 - (2xy)^2$

[ $a^2 - b^2 = (a+b)(a-b)$ সূত্র প্রয়োগ করে ]

$= (x^2y + 2xy)(x^2y - 2xy)$

প্রতিটি উৎপাদক থেকে $xy$ কমন নিয়ে পাই,

$= xy(x + 2) \cdot xy(x - 2)$

$= x^2y^2(x + 2)(x - 2)$

উত্তর: $\color{#059669}{\mathbf{\boxed{x^2y^2(x + 2)(x - 2)}}}$

(vi) $a^4 + 4a^2b^2 + 4b^4$

$= (a^2)^2 + 2 \cdot a^2 \cdot 2b^2 + (2b^2)^2$

$= (a^2 + 2b^2)^2$

$= (a^2 + 2b^2)(a^2 + 2b^2)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(a^2 + 2b^2)(a^2 + 2b^2)}}}$

(vii) $4x^2 - 16$

প্রথমে 4 কমন নিই,

$= 4(x^2 - 4)$

$= 4(x^2 - 2^2)$

$= 4(x + 2)(x - 2)$

উত্তর: $\color{#059669}{\mathbf{\boxed{4(x + 2)(x - 2)}}}$

(viii) $121 - 36x^2$

$= (11)^2 - (6x)^2$

$= (11 + 6x)(11 - 6x)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(11 + 6x)(11 - 6x)}}}$

(ix) $x^2y^2 - p^2q^2$

$= (xy)^2 - (pq)^2$

$= (xy + pq)(xy - pq)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(xy + pq)(xy - pq)}}}$

(x) $80m^2 - 125$

প্রথমে 5 কমন নিই,

$= 5(16m^2 - 25)$

$= 5\{(4m)^2 - (5)^2\}$

$= 5(4m + 5)(4m - 5)$

উত্তর: $\color{#059669}{\mathbf{\boxed{5(4m + 5)(4m - 5)}}}$

(xi) $ax^2 - ay^2$

প্রথমে $a$ কমন নিই,

$= a(x^2 - y^2)$

$= a(x + y)(x - y)$

উত্তর: $\color{#059669}{\mathbf{\boxed{a(x + y)(x - y)}}}$

(xii) $1 - (m + n)^2$

$= (1)^2 - (m + n)^2$

$= \{1 + (m + n)\}\{1 - (m + n)\}$

$= (1 + m + n)(1 - m - n)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(1 + m + n)(1 - m - n)}}}$

(xiii) $(2a - b - c)^2 - (a - 2b - c)^2$

$= \{(2a - b - c) + (a - 2b - c)\}\{(2a - b - c) - (a - 2b - c)\}$

$= (2a - b - c + a - 2b - c)(2a - b - c - a + 2b + c)$

$= (3a - 3b - 2c)(a + b)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(a + b)(3a - 3b - 2c)}}}$

(xiv) $x^2 - 2xy - 3y^2$

রাশিটিকে মধ্যপদ বিশ্লেষণ (Middle term factorization) করে বা সূত্র সাজিয়ে পাই,

$= x^2 - 2xy + y^2 - 4y^2$

$= (x - y)^2 - (2y)^2$

$= \{(x - y) + 2y\}\{(x - y) - 2y\}$

$= (x + y)(x - 3y)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(x + y)(x - 3y)}}}$

(xv) $x^2 + 9y^2 + 6xy - z^2$

$= (x^2 + 6xy + 9y^2) - z^2$

$= \{(x)^2 + 2 \cdot x \cdot 3y + (3y)^2\} - z^2$

$= (x + 3y)^2 - (z)^2$

$= (x + 3y + z)(x + 3y - z)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(x + 3y + z)(x + 3y - z)}}}$

(xvi) $a^2 - b^2 + 2bc - c^2$

$= a^2 - (b^2 - 2bc + c^2)$

$= a^2 - (b - c)^2$

$= \{a + (b - c)\}\{a - (b - c)\}$

$= (a + b - c)(a - b + c)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(a + b - c)(a - b + c)}}}$

(xvii) $a^2(b - c)^2 - b^2(c - a)^2$

$= \{a(b - c)\}^2 - \{b(c - a)\}^2$

$= \{a(b - c) + b(c - a)\}\{a(b - c) - b(c - a)\}$

$= (ab - ac + bc - ab)(ab - ac - bc + ab)$

$= (bc - ac)(2ab - ac - bc)$

$= c(b - a)(2ab - ac - bc)$

উত্তর: $\color{#059669}{\mathbf{\boxed{c(b - a)(2ab - ac - bc)}}}$

(xviii) $x^2 - y^2 - 6yz - 9z^2$

$= x^2 - (y^2 + 6yz + 9z^2)$

$= x^2 - \{(y)^2 + 2 \cdot y \cdot 3z + (3z)^2\}$

$= x^2 - (y + 3z)^2$

$= \{x + (y + 3z)\}\{x - (y + 3z)\}$

$= (x + y + 3z)(x - y - 3z)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(x + y + 3z)(x - y - 3z)}}}$

(xix) $x^2 - y^2 + 4x - 4y$

$= (x^2 - y^2) + (4x - 4y)$

$= (x + y)(x - y) + 4(x - y)$

$= (x - y)(x + y + 4)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(x - y)(x + y + 4)}}}$

(xx) $a^2 - b^2 + c^2 - d^2 - 2(ac - bd)$

$= a^2 - b^2 + c^2 - d^2 - 2ac + 2bd$

পদগুলিকে সাজিয়ে পাই,

$= (a^2 - 2ac + c^2) - (b^2 - 2bd + d^2)$

$= (a - c)^2 - (b - d)^2$

$= \{(a - c) + (b - d)\}\{(a - c) - (b - d)\}$

$= (a - c + b - d)(a - c - b + d)$

$= (a + b - c - d)(a - b - c + d)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(a + b - c - d)(a - b - c + d)}}}$
1) উৎপাদকে বিশ্লেষণ করি — (চলমান)

(xxi) $2ab - a^2 - b^2 + c^2$

(xxi) $2ab - a^2 - b^2 + c^2$

$= c^2 - (a^2 - 2ab + b^2)$

$= c^2 - (a - b)^2$

$= \{c + (a - b)\}\{c - (a - b)\}$

$= (c + a - b)(c - a + b)$

সাজিয়ে লিখলে, $= (a - b + c)(c - a + b)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(a - b + c)(c - a + b)}}}$

(xxii) $36x^2 - 16a^2 - 24ab - 9b^2$

$= 36x^2 - (16a^2 + 24ab + 9b^2)$

$= (6x)^2 - \{(4a)^2 + 2 \cdot 4a \cdot 3b + (3b)^2\}$

$= (6x)^2 - (4a + 3b)^2$

$= \{6x + (4a + 3b)\}\{6x - (4a + 3b)\}$

$= (6x + 4a + 3b)(6x - 4a - 3b)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(6x + 4a + 3b)(6x - 4a - 3b)}}}$

(xxiii) $a^2 - 1 + 2b - b^2$

$= a^2 - (1 - 2b + b^2)$

$= a^2 - (1 - b)^2$

$= \{a + (1 - b)\}\{a - (1 - b)\}$

$= (a - b + 1)(a + b - 1)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(a - b + 1)(a + b - 1)}}}$

(xxiv) $a^2 - 2a - b^2 + 2b$

$= (a^2 - b^2) - (2a - 2b)$

$= (a + b)(a - b) - 2(a - b)$

$= (a - b)(a + b - 2)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(a - b)(a + b - 2)}}}$

(xxv) $(a^2 - b^2)(c^2 - d^2) - 4abcd$

$= a^2c^2 - a^2d^2 - b^2c^2 + b^2d^2 - 2abcd - 2abcd$

সাজিয়ে পাই,

$= (a^2c^2 - 2abcd + b^2d^2) - (a^2d^2 + 2abcd + b^2c^2)$

$= \{(ac)^2 - 2(ac)(bd) + (bd)^2\} - \{(ad)^2 + 2(ad)(bc) + (bc)^2\}$

$= (ac - bd)^2 - (ad + bc)^2$

$= \{(ac - bd) + (ad + bc)\}\{(ac - bd) - (ad + bc)\}$

$= (ac - bd + ad + bc)(ac - bd - ad - bc)$

$= (ac + ad + bc - bd)(ac - ad - bc - bd)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(ac + ad + bc - bd)(ac - ad - bc - bd)}}}$

(xxvi) $a^2 - b^2 - 4ac + 4bc$

$= (a^2 - b^2) - 4c(a - b)$

$= (a + b)(a - b) - 4c(a - b)$

$= (a - b)(a + b - 4c)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(a - b)(a + b - 4c)}}}$

(xxvii) $(a^2 - b^2 - c^2 + d^2)^2 - 4(ad - bc)^2$

$= (a^2 - b^2 - c^2 + d^2)^2 - \{2(ad - bc)\}^2$

$= \{(a^2 - b^2 - c^2 + d^2) + (2ad - 2bc)\}\{(a^2 - b^2 - c^2 + d^2) - (2ad - 2bc)\}$

$= (a^2 + 2ad + d^2 - b^2 - 2bc - c^2)(a^2 - 2ad + d^2 - b^2 + 2bc - c^2)$

$= \{(a + d)^2 - (b + c)^2\}\{(a - d)^2 - (b - c)^2\}$

$= (a + d + b + c)(a + d - b - c)(a - d + b - c)(a - d - b + c)$

$= (a + b + c + d)(a - b - c + d)(a + b - c - d)(a - b + c - d)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(a+b+c+d)(a-b-c+d)(a+b-c-d)(a-b+c-d)}}}$

(xxviii) $3x^2 - y^2 + z^2 - 2xy - 4xz$

রাশিটিকে সাজিয়ে পাই,

$= 4x^2 - 4xz + z^2 - x^2 - 2xy - y^2$

$= (4x^2 - 4xz + z^2) - (x^2 + 2xy + y^2)$

$= \{(2x)^2 - 2(2x)(z) + z^2\} - (x + y)^2$

$= (2x - z)^2 - (x + y)^2$

$= \{(2x - z) + (x + y)\}\{(2x - z) - (x + y)\}$

$= (2x - z + x + y)(2x - z - x - y)$

$= (3x + y - z)(x - y - z)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(3x + y - z)(x - y - z)}}}$

(viii) $3x^2 - y^2 + z^2 - 2xy - 4xz$ (পুনরাবৃত্তি)
(ix) $3x^4 - 4x^2y^2 + y^4$
(x) $p^4 - 2p^2q^2 - 15q^4$
(xi) $x^8 + x^4y^4 + y^8$

(i) $81x^4 + 4y^4$

$= (9x^2)^2 + (2y^2)^2$

[ $a^2 + b^2 = (a+b)^2 - 2ab$ সূত্র প্রয়োগ করে ]

$= (9x^2 + 2y^2)^2 - 2(9x^2)(2y^2)$

$= (9x^2 + 2y^2)^2 - 36x^2y^2$

$= (9x^2 + 2y^2)^2 - (6xy)^2$

$= (9x^2 + 2y^2 + 6xy)(9x^2 + 2y^2 - 6xy)$

$= (9x^2 + 6xy + 2y^2)(9x^2 - 6xy + 2y^2)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(9x^2 + 6xy + 2y^2)(9x^2 - 6xy + 2y^2)}}}$

(ii) $p^4 - 13p^2q^2 + 4q^4$

$= (p^2)^2 - 4p^2q^2 + (2q^2)^2 - 9p^2q^2$

$= \{(p^2)^2 - 2 \cdot p^2 \cdot 2q^2 + (2q^2)^2\} - (3pq)^2$

$= (p^2 - 2q^2)^2 - (3pq)^2$

$= (p^2 - 2q^2 + 3pq)(p^2 - 2q^2 - 3pq)$

$= (p^2 + 3pq - 2q^2)(p^2 - 3pq - 2q^2)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(p^2 + 3pq - 2q^2)(p^2 - 3pq - 2q^2)}}}$

(iii) $x^8 - 16y^8$

$= (x^4)^2 - (4y^4)^2$

$= (x^4 + 4y^4)(x^4 - 4y^4)$

$= \{(x^2)^2 + (2y^2)^2\}\{(x^2)^2 - (2y^2)^2\}$

$= \{(x^2 + 2y^2)^2 - 2(x^2)(2y^2)\}(x^2 + 2y^2)(x^2 - 2y^2)$

$= \{(x^2 + 2y^2)^2 - (2xy)^2\}(x^2 + 2y^2)(x^2 - 2y^2)$

$= (x^2 + 2y^2 + 2xy)(x^2 + 2y^2 - 2xy)(x^2 + 2y^2)(x^2 - 2y^2)$

$= (x^2 + 2xy + 2y^2)(x^2 - 2xy + 2y^2)(x^2 + 2y^2)(x^2 - 2y^2)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(x^2 + 2xy + 2y^2)(x^2 - 2xy + 2y^2)(x^2 + 2y^2)(x^2 - 2y^2)}}}$

(iv) $x^4 + x^2y^2 + y^4$

$= (x^2)^2 + 2x^2y^2 + (y^2)^2 - x^2y^2$

$= (x^2 + y^2)^2 - (xy)^2$

$= (x^2 + y^2 + xy)(x^2 + y^2 - xy)$

$= (x^2 + xy + y^2)(x^2 - xy + y^2)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(x^2 + xy + y^2)(x^2 - xy + y^2)}}}$

(v) $3x^4 + 2x^2y^2 - y^4$

মধ্যপদ বিশ্লেষণ করে পাই,

$= 3x^4 + 3x^2y^2 - x^2y^2 - y^4$

$= 3x^2(x^2 + y^2) - y^2(x^2 + y^2)$

$= (x^2 + y^2)(3x^2 - y^2)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(x^2 + y^2)(3x^2 - y^2)}}}$

(vi) $x^4 + x^2 + 1$

$= (x^2)^2 + 2x^2 + 1^2 - x^2$

$= (x^2 + 1)^2 - (x)^2$

$= (x^2 + 1 + x)(x^2 + 1 - x)$

$= (x^2 + x + 1)(x^2 - x + 1)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(x^2 + x + 1)(x^2 - x + 1)}}}$

(vii) $x^4 + 6x^2y^2 + 8y^4$

মধ্যপদ বিশ্লেষণ করে পাই,

$= x^4 + 4x^2y^2 + 2x^2y^2 + 8y^4$

$= x^2(x^2 + 4y^2) + 2y^2(x^2 + 4y^2)$

$= (x^2 + 4y^2)(x^2 + 2y^2)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(x^2 + 4y^2)(x^2 + 2y^2)}}}$

(ix) $3x^4 - 4x^2y^2 + y^4$

মধ্যপদ বিশ্লেষণ করে পাই,

$= 3x^4 - 3x^2y^2 - x^2y^2 + y^4$

$= 3x^2(x^2 - y^2) - y^2(x^2 - y^2)$

$= (x^2 - y^2)(3x^2 - y^2)$

$= (x + y)(x - y)(3x^2 - y^2)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(x + y)(x - y)(3x^2 - y^2)}}}$

(x) $p^4 - 2p^2q^2 - 15q^4$

মধ্যপদ বিশ্লেষণ করে পাই ($15 = 5 \times 3$, $5 - 3 = 2$),

$= p^4 - 5p^2q^2 + 3p^2q^2 - 15q^4$

$= p^2(p^2 - 5q^2) + 3q^2(p^2 - 5q^2)$

$= (p^2 - 5q^2)(p^2 + 3q^2)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(p^2 - 5q^2)(p^2 + 3q^2)}}}$

(xi) $x^8 + x^4y^4 + y^8$

$= (x^4)^2 + 2x^4y^4 + (y^4)^2 - x^4y^4$

$= (x^4 + y^4)^2 - (x^2y^2)^2$

$= (x^4 + y^4 + x^2y^2)(x^4 + y^4 - x^2y^2)$

$= (x^4 + x^2y^2 + y^4)(x^4 - x^2y^2 + y^4)$

[প্রথম উৎপাদকটিকে আবার ভাঙা যায়, যেমনটা (iv) নম্বর অংকে করা হয়েছে]

$= (x^2 + xy + y^2)(x^2 - xy + y^2)(x^4 - x^2y^2 + y^4)$

উত্তর: $\color{#059669}{\mathbf{\boxed{(x^2 + xy + y^2)(x^2 - xy + y^2)(x^4 - x^2y^2 + y^4)}}}$
