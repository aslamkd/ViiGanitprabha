2. (a) আমার বয়স $x$ বছর। পল্লবী আমার থেকে 2 বছরের বড়ো। আমাদের দুজনের মোট বয়স হিসাব করি।

আমার বয়স $= x$ বছর

পল্লবী আমার থেকে 2 বছরের বড়ো, তাই পল্লবীর বয়স $= (x + 2)$ বছর

আমাদের দুজনের মোট বয়স $= x + (x + 2)$ বছর

$= x + x + 2$ বছর

$= 2x + 2$ বছর

$= 2(x + 1)$ বছর

উত্তর: আমাদের দুজনের মোট বয়স $\color{#059669}{\mathbf{\boxed{2(x + 1)}}}$ বছর।
2. (b) আজ আমি $x$ টি ফুলের মালা গেঁথেছি। মীর আমার গাঁথা মালার সংখ্যার দ্বিগুণের থেকে 6টি বেশি মালা গেঁথেছে। আমি ও মীর দুজনে মোট কতগুলি ফুলের মালা গেঁথেছি হিসাব করি।

আমি মালা গেঁথেছি $= x$ টি

মীর মালা গেঁথেছে আমার গাঁথা মালার দ্বিগুণের থেকে 6টি বেশি।

অর্থাৎ, মীর মালা গেঁথেছে $= (2x + 6)$ টি

আমি ও মীর দুজনে মোট মালা গেঁথেছি $= x + (2x + 6)$ টি

$= x + 2x + 6$ টি

$= 3x + 6$ টি

$= 3(x + 2)$ টি

উত্তর: আমি ও মীর দুজনে মোট $\color{#059669}{\mathbf{\boxed{3(x + 2)}}}$ টি ফুলের মালা গেঁথেছি।
2. (c) রাতুল আজকে $x$ টাকার পেয়ারা, $(x + 15)$ টাকার আপেল, $(2x + 3)$ টাকার শশা কিনল। রাতুল আজকে মোট কত টাকার ফল কিনল হিসাব করি।

রাতুল পেয়ারা কিনেছে $= x$ টাকার

রাতুল আপেল কিনেছে $= (x + 15)$ টাকার

রাতুল শশা কিনেছে $= (2x + 3)$ টাকার

রাতুল মোট ফল কিনল $= x + (x + 15) + (2x + 3)$ টাকার

$= x + x + 15 + 2x + 3$ টাকার

$= (x + x + 2x) + (15 + 3)$ টাকার

$= 4x + 18$ টাকার

$= 2(2x + 9)$ টাকার

উত্তর: রাতুল আজকে মোট $\color{#059669}{\mathbf{\boxed{2(2x + 9)}}}$ টাকার ফল কিনল।
2. (d) গতবছরে ফিরোজা $x$ দিন স্কুলে উপস্থিত ছিল। ফিরোজার বন্ধু মোহিনী $(3x + 13)$ দিন স্কুলে উপস্থিত ছিল। গতবছরে স্কুলে মোহিনীর উপস্থিতি ফিরোজার চেয়ে কত বেশি ছিল হিসাব করি।

মোহিনী স্কুলে উপস্থিত ছিল $= (3x + 13)$ দিন

ফিরোজা স্কুলে উপস্থিত ছিল $= x$ দিন

মোহিনীর উপস্থিতি ফিরোজার চেয়ে বেশি ছিল $= (3x + 13) - x$ দিন

$= 3x + 13 - x$ দিন

$= (3x - x) + 13$ দিন

$= 2x + 13$ দিন

উত্তর: গতবছরে স্কুলে মোহিনীর উপস্থিতি ফিরোজার চেয়ে $\color{#059669}{\mathbf{\boxed{2x + 13}}}$ দিন বেশি ছিল।
2. (e) দীপুদা আজ $(2x + 19)$ টি কাগজ বিক্রি করেছে। কিন্তু গতকাল সে $(5x - 8)$ টি কাগজ বিক্রি করেছিল। দীপুদা আজকের তুলনায় গতকাল কত বেশি কাগজ বিক্রি করেছিল হিসাব করি।

দীপুদা গতকাল কাগজ বিক্রি করেছিল $= (5x - 8)$ টি

দীপুদা আজ কাগজ বিক্রি করেছে $= (2x + 19)$ টি

দীপুদা আজকের তুলনায় গতকাল বেশি কাগজ বিক্রি করেছিল $= (5x - 8) - (2x + 19)$ টি

$= 5x - 8 - 2x - 19$ টি

$= (5x - 2x) - (8 + 19)$ টি

$= 3x - 27$ টি

$= 3(x - 9)$ টি

উত্তর: দীপুদা আজকের তুলনায় গতকাল $\color{#059669}{\mathbf{\boxed{3(x - 9)}}}$ টি বেশি কাগজ বিক্রি করেছিল।
2. (f) পরেশবাবু প্রতি মাসে $8x$ টাকা আয় করেন। কিন্তু প্রতি মাসে তিনি $(3x - 15)$ টাকা ব্যয় করেন। তিনি প্রতিমাসে কত টাকা সঞ্চয় করেন হিসাব করি।

পরেশবাবু প্রতি মাসে আয় করেন $= 8x$ টাকা

তিনি প্রতি মাসে ব্যয় করেন $= (3x - 15)$ টাকা

আমরা জানি, সঞ্চয় = আয় - ব্যয়

তিনি প্রতিমাসে সঞ্চয় করেন $= 8x - (3x - 15)$ টাকা

$= 8x - 3x + 15$ টাকা

$= 5x + 15$ টাকা

$= 5(x + 3)$ টাকা

উত্তর: তিনি প্রতিমাসে $\color{#059669}{\mathbf{\boxed{5(x + 3)}}}$ টাকা সঞ্চয় করেন।
3. যোগ করি:
(i) $3a+b ; 2a+4b ; 5a-b$
(ii) $5a-4 ; 2a+3 ; 2a-4$
(iii) $6a^2+7a+3 ; 9a^2-2a+7 ; 4a^2-2a+9$
(iv) $2a^2b+5b^2a+7 ; 3a^2b-2b^2a+6 ; 8a^2b-b^2a+9$
(v) $4xy+5x+7y ; -4xy-y-3x ; 3xy-3y+2x$

(i) $3a+b ; 2a+4b ; 5a-b$

$= (3a + b) + (2a + 4b) + (5a - b)$

$= 3a + b + 2a + 4b + 5a - b$

$= (3a + 2a + 5a) + (b + 4b - b)$

$= 10a + 4b$

$= 2(5a + 2b)$

উত্তর: নির্ণেয় যোগফল $\color{#059669}{\mathbf{\boxed{2(5a + 2b)}}}$

(ii) $5a-4 ; 2a+3 ; 2a-4$

$= (5a - 4) + (2a + 3) + (2a - 4)$

$= 5a - 4 + 2a + 3 + 2a - 4$

$= (5a + 2a + 2a) + (-4 + 3 - 4)$

$= 9a - 5$

উত্তর: নির্ণেয় যোগফল $\color{#059669}{\mathbf{\boxed{9a - 5}}}$

(iii) $6a^2+7a+3 ; 9a^2-2a+7 ; 4a^2-2a+9$

$= (6a^2 + 7a + 3) + (9a^2 - 2a + 7) + (4a^2 - 2a + 9)$

$= 6a^2 + 7a + 3 + 9a^2 - 2a + 7 + 4a^2 - 2a + 9$

$= (6a^2 + 9a^2 + 4a^2) + (7a - 2a - 2a) + (3 + 7 + 9)$

$= 19a^2 + 3a + 19$

উত্তর: নির্ণেয় যোগফল $\color{#059669}{\mathbf{\boxed{19a^2 + 3a + 19}}}$

(iv) $2a^2b+5b^2a+7 ; 3a^2b-2b^2a+6 ; 8a^2b-b^2a+9$

$= (2a^2b + 5ab^2 + 7) + (3a^2b - 2ab^2 + 6) + (8a^2b - ab^2 + 9)$

$= 2a^2b + 5ab^2 + 7 + 3a^2b - 2ab^2 + 6 + 8a^2b - ab^2 + 9$

$= (2a^2b + 3a^2b + 8a^2b) + (5ab^2 - 2ab^2 - ab^2) + (7 + 6 + 9)$

$= 13a^2b + 2ab^2 + 22$

উত্তর: নির্ণেয় যোগফল $\color{#059669}{\mathbf{\boxed{13a^2b + 2ab^2 + 22}}}$

(v) $4xy+5x+7y ; -4xy-y-3x ; 3xy-3y+2x$

$= (4xy + 5x + 7y) + (-4xy - y - 3x) + (3xy - 3y + 2x)$

$= 4xy + 5x + 7y - 4xy - y - 3x + 3xy - 3y + 2x$

$= (4xy - 4xy + 3xy) + (5x - 3x + 2x) + (7y - y - 3y)$

$= 3xy + 4x + 3y$

উত্তর: নির্ণেয় যোগফল $\color{#059669}{\mathbf{\boxed{3xy + 4x + 3y}}}$
4. বিয়োগ করি:
(i) $(8x+6y)$ থেকে $(2x+3y)$
(ii) $(-3m^2+2m+2)$ থেকে $(m^2-2)$
(iii) $(2x+3y)$ থেকে $(8x+4y+7)$
(iv) $(-9a^2+3a+2)$ থেকে $(5a^2+2a-1)$
(v) $x$ থেকে $(-2x^2+3y^2)$
(vi) $3x^2+5xy$ থেকে $2x^2+xy+3y^2$

(i) $(8x+6y)$ থেকে $(2x+3y)$

$= (8x + 6y) - (2x + 3y)$

$= 8x + 6y - 2x - 3y$

$= (8x - 2x) + (6y - 3y)$

$= 6x + 3y$

$= 3(2x + y)$

উত্তর: নির্ণেয় বিয়োগফল $\color{#059669}{\mathbf{\boxed{3(2x + y)}}}$

(ii) $(-3m^2+2m+2)$ থেকে $(m^2-2)$

$= (-3m^2 + 2m + 2) - (m^2 - 2)$

$= -3m^2 + 2m + 2 - m^2 + 2$

$= (-3m^2 - m^2) + 2m + (2 + 2)$

$= -4m^2 + 2m + 4$

উত্তর: নির্ণেয় বিয়োগফল $\color{#059669}{\mathbf{\boxed{-4m^2 + 2m + 4}}}$

(iii) $(2x+3y)$ থেকে $(8x+4y+7)$

$= (2x + 3y) - (8x + 4y + 7)$

$= 2x + 3y - 8x - 4y - 7$

$= (2x - 8x) + (3y - 4y) - 7$

$= -6x - y - 7$

$= -(6x + y + 7)$

উত্তর: নির্ণেয় বিয়োগফল $\color{#059669}{\mathbf{\boxed{-(6x + y + 7)}}}$

(iv) $(-9a^2+3a+2)$ থেকে $(5a^2+2a-1)$

$= (-9a^2 + 3a + 2) - (5a^2 + 2a - 1)$

$= -9a^2 + 3a + 2 - 5a^2 - 2a + 1$

$= (-9a^2 - 5a^2) + (3a - 2a) + (2 + 1)$

$= -14a^2 + a + 3$

উত্তর: নির্ণেয় বিয়োগফল $\color{#059669}{\mathbf{\boxed{-14a^2 + a + 3}}}$

(v) $x$ থেকে $(-2x^2+3y^2)$

$= x - (-2x^2 + 3y^2)$

$= x + 2x^2 - 3y^2$

$= 2x^2 + x - 3y^2$

উত্তর: নির্ণেয় বিয়োগফল $\color{#059669}{\mathbf{\boxed{2x^2 + x - 3y^2}}}$

(vi) $3x^2+5xy$ থেকে $2x^2+xy+3y^2$

$= (3x^2 + 5xy) - (2x^2 + xy + 3y^2)$

$= 3x^2 + 5xy - 2x^2 - xy - 3y^2$

$= (3x^2 - 2x^2) + (5xy - xy) - 3y^2$

$= x^2 + 4xy - 3y^2$

উত্তর: নির্ণেয় বিয়োগফল $\color{#059669}{\mathbf{\boxed{x^2 + 4xy - 3y^2}}}$

6. রামুর $(13x^2 + x - 3)$ টাকা ছিল। সে $(4x^2 - 3x - 12)$ টাকা খরচ করল। এখন হিসাব করে দেখি তার কাছে আর কত টাকা আছে।

রামুর কাছে ছিল $= (13x^2 + x - 3)$ টাকা

সে খরচ করল $= (4x^2 - 3x - 12)$ টাকা

তার কাছে আর টাকা আছে $= (13x^2 + x - 3) - (4x^2 - 3x - 12)$ টাকা

$= 13x^2 + x - 3 - 4x^2 + 3x + 12$ টাকা

$= (13x^2 - 4x^2) + (x + 3x) + (-3 + 12)$ টাকা

$= 9x^2 + 4x + 9$ টাকা

উত্তর: এখন রামুর কাছে আর $\color{#059669}{\mathbf{\boxed{9x^2 + 4x + 9}}}$ টাকা আছে।
7. একটি ত্রিভুজের তিনটি বাহুর দৈর্ঘ্য যথাক্রমে $(x+4)$ সেমি., $(2x+1)$ সেমি. ও $(4x-8)$ সেমি.। এই ত্রিভুজের পরিসীমা কত তা হিসাব করে দেখি।

আমরা জানি, ত্রিভুজের পরিসীমা = তিনটি বাহুর দৈর্ঘ্যের যোগফল

ত্রিভুজের তিনটি বাহুর দৈর্ঘ্য যথাক্রমে $(x+4)$ সেমি., $(2x+1)$ সেমি. ও $(4x-8)$ সেমি.

অতএব, ত্রিভুজটির পরিসীমা $= (x + 4) + (2x + 1) + (4x - 8)$ সেমি.

$= x + 4 + 2x + 1 + 4x - 8$ সেমি.

$= (x + 2x + 4x) + (4 + 1 - 8)$ সেমি.

$= 7x + (5 - 8)$ সেমি.

$= (7x - 3)$ সেমি.

উত্তর: ত্রিভুজটির পরিসীমা $\color{#059669}{\mathbf{\boxed{7x - 3}}}$ সেমি.।
8. $-8x^2+8x+1$-এর সাথে কত যোগ করলে $-14x^2+11x-3$ পাব হিসাব করি।

[যেহেতু যোগফল দেওয়া আছে, তাই যোগফল থেকে প্রথম সংখ্যাটি বিয়োগ করলেই নির্ণেয় সংখ্যাটি পাওয়া যাবে।]

নির্ণেয় সংখ্যাটি হলো = $(-14x^2+11x-3) - (-8x^2+8x+1)$

$= -14x^2 + 11x - 3 + 8x^2 - 8x - 1$

$= (-14x^2 + 8x^2) + (11x - 8x) + (-3 - 1)$

$= -6x^2 + 3x - 4$

উত্তর: $\color{#059669}{\mathbf{\boxed{-6x^2 + 3x - 4}}}$ যোগ করতে হবে।
9. $-11x-7y-9z$ -থেকে কত বিয়োগ করলে $-7x+3y-5z$ পাব হিসাব করি।

[যেহেতু বিয়োগফল দেওয়া আছে, তাই প্রথম সংখ্যা থেকে বিয়োগফলটি বিয়োগ করলেই নির্ণেয় সংখ্যাটি পাওয়া যাবে।]

নির্ণেয় সংখ্যাটি হলো = $(-11x - 7y - 9z) - (-7x + 3y - 5z)$

$= -11x - 7y - 9z + 7x - 3y + 5z$

$= (-11x + 7x) + (-7y - 3y) + (-9z + 5z)$

$= -4x - 10y - 4z$

$= -2(2x + 5y + 2z)$

উত্তর: $\color{#059669}{\mathbf{\boxed{-2(2x + 5y + 2z)}}}$ বিয়োগ করতে হবে।
10. $(3x^2+4x)$ ও $(5x^2-x)$ -এর যোগফল $(3x-5x^2)$ -এর থেকে কত বেশি হিসাব করি।

প্রথম ধাপ: $(3x^2+4x)$ ও $(5x^2-x)$ এর যোগফল নির্ণয়

$= (3x^2 + 4x) + (5x^2 - x)$

$= 3x^2 + 4x + 5x^2 - x$

$= 8x^2 + 3x$

দ্বিতীয় ধাপ: এই যোগফল $(3x-5x^2)$ এর থেকে কত বেশি তা নির্ণয় করতে হবে।

নির্ণেয় মান $= (8x^2 + 3x) - (3x - 5x^2)$

$= 8x^2 + 3x - 3x + 5x^2$

$= (8x^2 + 5x^2) + (3x - 3x)$

$= 13x^2 + 0$

$= 13x^2$

উত্তর: যোগফলটি $(3x-5x^2)$ -এর থেকে $\color{#059669}{\mathbf{\boxed{13x^2}}}$ বেশি।
11. $(5+9x)$ এবং $(6-7x+4x^2)$ এর যোগফল থেকে $(x^2-9x)$ এবং $(-2x^2+3x+5)$ এর যোগফল বিয়োগ করি।

প্রথম অংশ: $(5+9x)$ এবং $(6-7x+4x^2)$ এর যোগফল

$= (5 + 9x) + (6 - 7x + 4x^2)$

$= 5 + 9x + 6 - 7x + 4x^2$

$= 4x^2 + 2x + 11$

দ্বিতীয় অংশ: $(x^2-9x)$ এবং $(-2x^2+3x+5)$ এর যোগফল

$= (x^2 - 9x) + (-2x^2 + 3x + 5)$

$= x^2 - 9x - 2x^2 + 3x + 5$

$= -x^2 - 6x + 5$

তৃতীয় ধাপ: প্রথম যোগফল থেকে দ্বিতীয় যোগফল বিয়োগ

নির্ণেয় বিয়োগফল $= (4x^2 + 2x + 11) - (-x^2 - 6x + 5)$

$= 4x^2 + 2x + 11 + x^2 + 6x - 5$

$= (4x^2 + x^2) + (2x + 6x) + (11 - 5)$

$= 5x^2 + 8x + 6$

উত্তর: নির্ণেয় বিয়োগফল $\color{#059669}{\mathbf{\boxed{5x^2 + 8x + 6}}}$
