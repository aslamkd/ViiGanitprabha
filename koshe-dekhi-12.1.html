1. $(a+b)$ কে $(a+b)$ দিয়ে গুণ করলে নীচের কোনটি হবে দেখি।
(i) $a^2+b^2$    (ii) $(a+b)^2$    (iii) $2(a+b)$    (iv) $4ab$

$(a+b)$ কে $(a+b)$ দিয়ে গুণ করলে পাই,

$(a+b) \times (a+b) = (a+b)^2$

সঠিক উত্তর: $\color{#059669}{\mathbf{(ii) \ (a+b)^2}}$
2. $(x+7)^2 = x^2 + 14x + k$ হলে $k$ -এর মান নীচের কোনটি হবে লিখি।
(i) 14    (ii) 49    (iii) 7    (iv) কোনটিই নয়

বামপক্ষকে $(a+b)^2$ এর সূত্রে ভেঙে পাই:

$(x+7)^2 = x^2 + 2(x)(7) + 7^2 = x^2 + 14x + 49$

প্রদত্ত সমীকরণ: $x^2 + 14x + 49 = x^2 + 14x + k$

উভয়পক্ষ তুলনা করে পাই, $k = 49$

সঠিক উত্তর: $\color{#059669}{\mathbf{(ii) \ 49}}$
3. $a^2+b^2$ -এর সাথে কোন বীজগাণিতিক সংখ্যামালা যোগ করলে যোগফল একটি পূর্ণবর্গ সংখ্যামালা হবে তা লিখি।
(i) $4ab$    (ii) $-4ab$    (iii) $2ab$ বা $-2ab$    (iv) 0

আমরা জানি,

$a^2 + b^2 + 2ab = (a+b)^2$ [যা একটি পূর্ণবর্গ]

এবং, $a^2 + b^2 - 2ab = (a-b)^2$ [যা একটি পূর্ণবর্গ]

সুতরাং, $a^2+b^2$ এর সাথে $2ab$ বা $-2ab$ যোগ করলে যোগফল পূর্ণবর্গ হবে।

সঠিক উত্তর: $\color{#059669}{\mathbf{(iii) \ 2ab \text{ বা } -2ab}}$
4. $(a+b)^2 = a^2 + 6a + 9$ হলে $b$ -এর ধনাত্মক মান নীচের কোনটি হবে লিখি।
(i) 9    (ii) 6    (iii) 3    (iv) -3

ডানপক্ষকে পূর্ণবর্গাকারে প্রকাশ করে পাই:

$a^2 + 6a + 9 = (a)^2 + 2(a)(3) + (3)^2 = (a+3)^2$

প্রদত্ত সমীকরণ: $(a+b)^2 = (a+3)^2$

তুলনা করে পাই, $b = 3$

সঠিক উত্তর: $\color{#059669}{\mathbf{(iii) \ 3}}$
5. $x^2 + \frac{1}{4}x$ এর সাথে নীচের কোনটি যোগ করলে যোগফল পূর্ণবর্গ সংখ্যামালা হবে তা লিখি।
(i) $\frac{1}{64}$    (ii) $-\frac{1}{64}$    (iii) $\frac{1}{8}$    (iv) কোনটিই নয়

প্রদত্ত সংখ্যামালা: $x^2 + \frac{1}{4}x$

$= (x)^2 + 2(x)(\frac{1}{8})$

পূর্ণবর্গ হওয়ার জন্য $(\frac{1}{8})^2$ যোগ করতে হবে।

অর্থাৎ, যোগ করতে হবে: $(\frac{1}{8})^2 = \frac{1}{64}$

তাহলে এটি হবে: $(x)^2 + 2(x)(\frac{1}{8}) + (\frac{1}{8})^2 = (x + \frac{1}{8})^2$

সঠিক উত্তর: $\color{#059669}{\mathbf{(i) \ \frac{1}{64}}}$
6. (i) $k$ -এর কোন মান বা মানগুলির জন্য $c^2 + kc + \frac{1}{9}$ পূর্ণবর্গ হবে লিখি।

প্রদত্ত রাশি: $c^2 + kc + \frac{1}{9}$

$= (c)^2 + 2(c)(\frac{k}{2}) + (\frac{1}{3})^2$

রাশিটি পূর্ণবর্গ হতে হলে, মধ্যপদটি $2ab$ এর সমান হতে হবে।

$\therefore 2(c)(\frac{k}{2}) = \pm 2(c)(\frac{1}{3})$

বা, $kc = \pm \frac{2}{3}c$

বা, $k = \pm \frac{2}{3}$

উত্তর: $k$ এর মান $\color{#059669}{\mathbf{\frac{2}{3}}}$ বা $\color{#059669}{\mathbf{-\frac{2}{3}}}$ হতে পারে।
6. (ii) $9p^2 + \frac{1}{9p^2}$ সংখ্যামালাটি থেকে কোন সংখ্যা বা সংখ্যাগুলি বিয়োগ করলে বিয়োগফল পূর্ণবর্গ হবে তা নির্ণয় করি।

প্রদত্ত রাশি: $9p^2 + \frac{1}{9p^2}$

$= (3p)^2 + (\frac{1}{3p})^2$

পূর্ণবর্গ করতে হলে, এর সাথে $2ab$ যোগ বা বিয়োগ করতে হবে।

এখানে $2ab = 2(3p)(\frac{1}{3p}) = 2$

তাহলে, রাশিটিকে লেখা যায়:

$(3p)^2 + (\frac{1}{3p})^2 = (3p + \frac{1}{3p})^2 - 2(3p)(\frac{1}{3p}) = (3p + \frac{1}{3p})^2 - 2$ (এক্ষেত্রে -2 বিয়োগ করতে হবে)

অথবা, $(3p)^2 + (\frac{1}{3p})^2 = (3p - \frac{1}{3p})^2 + 2(3p)(\frac{1}{3p}) = (3p - \frac{1}{3p})^2 + 2$ (এক্ষেত্রে 2 বিয়োগ করতে হবে)

উত্তর: $\color{#059669}{\mathbf{2}}$ বা $\color{#059669}{\mathbf{-2}}$ বিয়োগ করতে হবে।
6. (iii) $(x - y)^2 = 4 - 4y + y^2$ হলে $x$ -এর মান কত তা নির্ণয় করি।

ডানপক্ষ: $4 - 4y + y^2$

$= (2)^2 - 2(2)(y) + (y)^2$

$= (2 - y)^2$

প্রদত্ত সমীকরণ: $(x - y)^2 = (2 - y)^2$

উভয়পক্ষের বর্গমূল করে বা তুলনা করে পাই,

$x - y = 2 - y$

বা, $x = 2 - y + y$

বা, $x = 2$

উত্তর: $x$ এর মান $\color{#059669}{\mathbf{2}}$।
6. (iv) $(c - 3)^2 = c^2 + kc + 9$ হলে $k$ -এর মান কী হবে তা লিখি।

বামপক্ষকে $(a-b)^2$ সূত্রে ভেঙে পাই:

$(c - 3)^2 = (c)^2 - 2(c)(3) + (3)^2 = c^2 - 6c + 9$

প্রদত্ত সমীকরণ: $c^2 - 6c + 9 = c^2 + kc + 9$

উভয়পক্ষ থেকে $c^2$ এবং $9$ বাদ দিয়ে পাই:

$-6c = kc$

বা, $k = -6$

উত্তর: $k$ এর মান $\color{#059669}{\mathbf{-6}}$।
7. সূত্রের সাহায্যে সরল করি।
(i) $(2q - 3z)^2 - 2(2q - 3z)(q - 3z) + (q - 3z)^2$

ধরি, $(2q - 3z) = a$ এবং $(q - 3z) = b$

তাহলে প্রদত্ত রাশিটি দাঁড়ায়: $a^2 - 2ab + b^2$

$= (a - b)^2$

এখন $a$ ও $b$ এর মান বসিয়ে পাই,

$= \{(2q - 3z) - (q - 3z)\}^2$

$= (2q - 3z - q + 3z)^2$

$= (2q - q - 3z + 3z)^2$

$= (q)^2 = q^2$

উত্তর: নির্ণেয় সরলফল $\color{#059669}{\mathbf{\boxed{q^2}}}$

ধরি, $(3p + 2q - 4r) = a$ এবং $(4r - 2p - q) = b$

তাহলে প্রদত্ত রাশিটি দাঁড়ায়: $a^2 + 2ab + b^2$

$= (a + b)^2$

এখন $a$ ও $b$ এর মান বসিয়ে পাই,

$= \{(3p + 2q - 4r) + (4r - 2p - q)\}^2$

$= (3p - 2p + 2q - q - 4r + 4r)^2$

$= (p + q)^2$

উত্তর: নির্ণেয় সরলফল $\color{#059669}{\mathbf{\boxed{(p + q)^2}}}$

9. পূর্ণবর্গাকারে প্রকাশ করে মান নির্ণয় করি।

$= (8a + 1)^2$

$= (8 \times 1 + 1)^2$

$= (8 + 1)^2$

$= (9)^2 = 81$

উত্তর: নির্ণেয় মান $\color{#059669}{\mathbf{\boxed{81}}}$
9. (ii) $25a^2 - 30ab + 9b^2$ যখন $a=3$ এবং $b=2$

$= (5a - 3b)^2$

$= (9)^2 = 81$
